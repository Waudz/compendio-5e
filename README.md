# Compêndio 5e 2.0

Nova aplicação experimental em React + TypeScript + Vite. O aplicativo anterior permanece independente.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Verificação

```bash
npm run build
npm test
```

## Entrega 1

- Menu lateral recolhível no desktop
- Seis seções com abas independentes
- Abas restauradas localmente ao reabrir
- Layout responsivo básico
- Conteúdo demonstrativo, sem autenticação ou Supabase

**Próximas entregas:** colunas verticais, arrastar abas, menu de contexto, dados reais e persistência por campanha.
